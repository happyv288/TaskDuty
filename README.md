# TaskDuty – Personal Task Manager

A responsive personal task management application built as part of the Techstudio Internship Program – Stage 1, Week 1.

## Features

- Create new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed or pending
- Filter tasks by category
- Filter tasks by completion status
- Form validation
- Due date validation
- Local task persistence using browser localStorage
- Responsive frontend design

## Task Fields

Each task contains:

- Title
- Description
- Due date
- Category
- Completion status

## Tech Stack

- React
- TypeScript
- React Router
- Tailwind CSS
- Vite
- Browser localStorage

## Getting Started

### 1. Clone the repository

...bash
git clone https://github.com/happyv288/TaskDuty.git
...

### 2. Open the project

...bash
cd TaskDuty
...

### 3. Go into the client folder

...bash
cd client
...

### 4. Install dependencies

...bash
npm install
...

### 5. Start the development server

...bash
npm run dev
...

Open the local URL provided by Vite in your browser.
